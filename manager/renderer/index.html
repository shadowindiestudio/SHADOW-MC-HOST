Connection Methods

Choose how players connect to your servers. ZeroTier is recommended for easy, secure multiplayer.

⭐ ZeroTier - Recommended

ZeroTier creates a virtual private network. Players connect using ZeroTier addresses like 10.x.x.x:25565.

Setup Guide:

  1. Install ZeroTier on all devices (server + player computers)
  2. Create a network at my.zerotier.com
  3. Join the same network on all devices
  4. Authorize all devices in the network
  5. Players connect using the ZeroTier IP shown above

🔗 Tailscale

  1. Install Tailscale on all devices

Note: Tailscale addresses work even behind NAT without port forwarding.

🏠 LAN / Local Network

Players on the same local network can connect directly using your local IP addresses.

Your Local IP Addresses:

How to use:

  1. Make sure your server and player computers are on the same network
  2. Players connect using one of the IP addresses above with the server port
  3. Example: 192.168.1.100:25565

Note: This only works on the same local network. For remote players, use ZeroTier or Tailscale.

🔌 Port Forwarding

Allow external players to connect by forwarding a port on your router.

Your Public IP: Detecting...
Connection Address: -
Local Port Status: Checking...

Router Configuration:

  1. Find your router's admin page (usually 192.168.1.1)
  2. Go to Port Forwarding / NAT settings
  3. Forward external port 25565 (TCP) to internal IP - port 25565
  4. Save and apply the changes

Note: Each player needs a unique external port. You may need to configure firewall rules too.
