- **[Electron](https://www.electronjs.org/)** - The foundation that enables cross-platform desktop applications with web technologies
- **[Node.js](https://nodejs.org/)** - The JavaScript runtime that powers our backend

### Minecraft Ecosystem
- **[PaperMC](https://papermc.io/)** - High-performance Minecraft server software
- **[SpigotMC](https://www.spigotmc.org/)** - The foundation for PaperMC
